# v1.6.2：速览删掉彩色四防条 + 先攻条固定宽高

> 真机 v1.6.1 已跑通（四防一排 ✓ 血条 ✓ 先攻条 ✓）。v1.6.2 **只修用户反馈的两处**，
> 不碰 token 上的四防一排 / 血条 / 蓝条 / Boss / 速览其它内容 / 骰子 / 设置窗口 / 五个入口。
> 规格文件（`docs/spec-*.md`）一个字没改。

## 1. 速览弹窗：删掉「彩色四防箭头条」

* **用户原话**：「图1在显示的预览部分不需要显示，直接修改下面对应的数值栏位就行」。
* **删的是**：`assets/glance.js` 里 `renderHpBlock()` 生成的 `<div class="gl4-def-row">`
  —— HP 绿条下面那条蓝 / 黄 / 绿 / 紫四块盾形夹片（`data-act="defense"`，
  点一下会把四项写进 token 四角的那排）。`assets/glance.css` 里对应的
  `.gl4-def-row / .gl4-def-chip*` 样式一并删掉（没有别的元素在用）。
* **保留的**：HP 数字 / 绿条 / 重伤线、回复力蓝条 + 圆点 + 「使用回复力」、血量按钮、
  **四防数值卡**（`.gl4-defs`：AC / 强韧 / 反射 / 意志 四张卡 —— 用户要改的就是这四个数）、
  六属性、技能、攻击与伤害、威能、专长、装备、锁 / Boss 开关、休整、底部说明。
* **不动的**：token 上画的那排四防（v1.6.1）在 `assets/background.core.js` 的 `barLayout()` 里，
  与速览的 HTML 无关，一行没改。`track.js` 的 `act === "defense"` 分支也保留（速览刷新时的
  `syncTokenStats()` 仍会补写四防 / 回复力分母）。

## 2. 先攻条：宽高改成常量（修「随投骰变窄」）

* **现象**：先攻条的宽度随内容变（投骰后点数 / 名字一变就窄一点），右侧留一片空白。
* **根因**：v1.4.0 的页面对 `.strip-ctl` 取 `scrollWidth`，再算 `max(410, 测量值 + 16)`。
* **修法**：见 `docs/initiative-v14.md` §12 ——
  `stripSizeFor(phase, collapsed, vw)` 返回常量（折叠 120×40 / 展开 720×(129|139|159)，
  仅视口太窄时缩）、页面不再量 DOM、后台 `snapStripSize()` 兜一道、
  卡片区 `.strip-items` 内部横向滚动且底色保持深色（空列表区域不透明）。
